# v0.6 modelling dynamics

This milestone adds advanced state-transition dynamics before extending persistence.

## Added

- Semi-Markov/state-time cohort engine with implicit tunnel-state tracking.
- Separate model-time and state-time piecewise transition schedules.
- Rate/hazard and probability semantics kept explicit and non-interchangeable.
- Joint competing-risk conversion for cause-specific rates.
- Full continuous-time generator conversion `P(t)=exp(Qt)` using uniformization.
- Age-specific background mortality integrated across birthdays.
- Standardized mortality ratios applied to mortality rates.
- Explicit rejection of automatic mortality/probability mixing when no coherent competing-risk rule exists.
- DSA and PSA wrappers for semi-Markov models.
- Editable table compiler for advanced dynamics.
- Advanced Markov Dynamics Streamlit workbench.
- Methodological documentation and dedicated unit tests.

## Deliberately deferred

The following are intentionally deferred to the next milestone:

- Markov/semi-Markov model JSON persistence.
- Save/load migration between homogeneous v0.5 and advanced v0.6 models.
- Audit-record export for schedules, mortality tables and hazard semantics.
- Consolidation of the advanced workbench into the main guided Markov page.

This separation keeps the modelling semantics stable before they are frozen into a versioned persistence format.
